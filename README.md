# 수월 학급 도구

교실에서 바로 쓰는 학급 도구 모음 웹앱입니다. 요정 타이머, 시간 안내판, 자리 바꾸기, 학생 추첨, 점수판, 반 배정이 들어 있습니다.

## 사용 방법
- GitHub Pages 주소로 열면 처음 한 번은 인터넷이 필요합니다. 한 번 열린 뒤에는 인터넷이 끊겨도 그 화면에서 계속 쓸 수 있습니다. 새로 고침하거나 다시 열 때는 인터넷이 필요합니다.
- 인터넷이 없는 교실에서는 `index.html` 파일을 컴퓨터에 내려받아 브라우저로 열면 인터넷 없이 동작합니다.
- GitHub Pages에 올릴 때는 `index.html`을 저장소 루트에 올리면 됩니다.
- 모든 설정은 각 컴퓨터(브라우저)에만 저장됩니다.

## 꾸미기
- ⚙ 꾸미기에서 배경 사진을 고르면 배너 그림은 그대로 두고 배너와 카드 색이 배경 색을 따라갑니다.
- 퇴근 요정과 어두운 유리도 여기서 설정합니다.

## 글꼴
모든 글씨는 런드리고딕(Regular · Bold)으로 표시됩니다. 글꼴이 index.html 안에 들어 있어서 따로 fonts 폴더가 필요 없어요. 글꼴 사용 조건은 LaundryGothic_license.pdf를 참고하세요.
